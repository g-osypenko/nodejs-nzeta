# Слід роботи з AI

Вимога DoD «з AI» (§3): ключові промпти — дослівно, відповіді студента на уточнювальні питання, фідбек до виходу AI.

**Інструмент:** Claude Code (агентний режим у VS Code: агент сам читає/редагує файли й запускає `npm run …`).
Коміти, зроблені з агентом, мають трейлер `Co-Authored-By: Claude …`.
Правила, за якими працює агент, — [`AGENTS.md`](../AGENTS.md) (теж є «входом» і змінюється, коли агент помиляється).

**Позначення:** 🧑 — написано студентом власноруч (дослівно, з орфографією оригіналу); 🤖 — підсумок відповіді агента.
