## 🤖 Аналіз завдання (`INFO/tasks/lab4.md`) і прогалини

| Вимога завдання                                    | Стан репозиторію                                    | Прогалина / питання студенту                                    |
| :------------------------------------------------- | :-------------------------------------------------- | :-------------------------------------------------------------- |
| CI: стиль, лінт, білд, тести, conventional commits | лише локальні git-хуки (husky)                      | хуки обходяться (`--no-verify`) — потрібна перевірка на сервері |
| мердж заблоковано без зеленого CI                  | `main` не захищена                                  | коли вмикати branch protection, якщо PR #2/#3 ще висять?        |
| CD → стейдж, доступний з інтернету                 | немає ні образу, ні хостингу                        | **куди деплоїти** — рішення студента                            |
| міграції: структура / дані / індекси окремо; seed  | один мігратор, усе в транзакції; plans у `001_init` | новий мігратор із фазами; seed — окрема команда                 |
| blue-green                                         | graceful shutdown є, `/health` є                    | залежить від хостингу                                           |
| `/version` з SHA                                   | є, але `GIT_COMMIT` ніде не задається               | вшити SHA в образ                                               |
