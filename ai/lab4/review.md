# Lab 4 · Рев'ю виходу AI: розбіжності зі spec і виправлення через вхід

Правило DoD: розбіжність виправляється **зміною входу** (spec / `AGENTS.md`), щоб наступна генерація не повторила помилку, а не лише патчем коду.

## 1. Seed-CLI у `shared/` імпортував `modules/auth` — порушення меж шарів

- **Що:** перша версія `src/shared/db/seed.cli.ts` імпортувала `hashPassword` з `modules/auth`, тобто `shared` залежав від модуля (`AGENTS.md` §3: «спільне — лише через `shared/`»).
- **Як помітили:** рев'ю диф-у до коміту.
- **Виправлення виходу:** CLI перенесено в корінь — [`src/seed.ts`](../../src/seed.ts), поруч зі `smoke.ts`; бібліотечна частина `shared/db/seed.ts` модулів не знає — `a07b2c4`.
- **Зміна входу:** `AGENTS.md`, розділ «CI/CD і міграції»: «точки входу й CLI, що збирають модулі, — у корені `src/`; `shared/` ніколи не імпортує `modules/`» — `40809a1`.

## 2. SHA GitHub Action узято «з пам'яті», а не з реєстру

- **Що:** у першому `ci.yml` `actions/upload-artifact` закріплено як `@ea165f…  # v4.6.2` — ні версію, ні SHA не перевіряли. Усі інші дії перед цим перевірено через `gh api`. Неперевірений SHA — або непрацюючий крок, або, гірше, чужий коміт.
- **Як помітили:** самоперевірка перед `actionlint`.
- **Виправлення виходу:** `v7.0.2` з SHA, отриманим через `gh api repos/actions/upload-artifact/commits/v7.0.2` — `4f759eb`.
- **Зміна входу:** `AGENTS.md`: «версії та SHA зовнішніх дій і пакетів — лише з реєстру, ніколи з пам'яті; реліз ≥ 2 тижнів; Actions закріплюються за SHA з коментарем-тегом» — `40809a1`.

## 3. Перший прогін CI: дві помилки, які локальні прогони не показали

- **Що:**
  - (a) крок `docker`: `curl | jq` без `pipefail` → хибна «готовність»;
  - (b) тест Лаби 3 з допуском ±50 мс за справжнім годинником — флак на повільнішому раннері.
- **Як помітили:** [run 42586051439](https://github.com/g-osypenko/nodejs-nzeta/actions/runs/42586051439) — `test` і `docker` червоні.
- **Виправлення виходу:**
  - фейковий `Date` у тесті — `e2d15a8`;
  - готовність за `curl` — `9976c42`.
- **Зміна входу:**
  - для всього workflow `defaults.run.shell: bash` (pipefail) — `9976c42`;
  - правило про детерміновані лічильники та час уже було, тест його порушував; додано уточнення про `pg_stat_*` — `40809a1`.
