# Звіт мутаційного тестування (Stryker)

**Відтворення:** `npm run test:mutation` (або `make mutation`) → HTML-звіт `reports/mutation/index.html`, JSON — `reports/mutation/mutation.json`. Конфігурація — [`stryker.config.mjs`](../../stryker.config.mjs).

**Що мутується:** `src/modules/**/*.service.ts`, увесь модуль `loader` (крім SQL-репозиторію), `src/shared/**` (крім підключення до БД і мігратора — їх перевіряють інтеграційні тести). Тести для мутантів — unit-набір (173 тести, < 1 с).
